# NPC DRAGONFEAR

> **Npc skill** — name: Dragon Fear; type: Multiple Target Status Attack; levels: 5; target: Self

A wide area effect that inflicts opponents in range with one of the following: [Stun](Status_Effects.md), [Curse](Status_Effects.md), [Silence](Status_Effects.md), or [Bleeding](Status_Effects.md).

| Skill Level | Area of Effect |
| --- | --- |
| 1 | 5x5 |
| 2 | 11x11 |
| 3 | 17x17 |
| 4 | 23x23 |
| 5 | 29x29 |


## Obtainable via

* Inverse Scale Lv. 1 when attacking
