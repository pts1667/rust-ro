# Play Dead

<!-- Skill info -->
- **Class:** Novice
- **Type:** Supportive
- **Levels:** 1
- **Quest:** Novice Skill Quest
- **SP cost:** 1
- **Duration:** Endless
- **Target:** Self


## Description

Play dead puts the user into a "dead" state, in which all monsters will not be aggressive and players in [PvP](PvP~d29d2.md) environments are unable to do damage. The user is unable to move or attack while in this state. There is no time limit for the duration in which a character plays dead.


## Notes

*  Unlike other evasion skills (such as [Hide](Hiding.md)), no monsters are able to detect a player in Play Dead state, including [MVP](MVP.md)s.
*  Play Dead can be canceled by a [Sage](Sage.md)'s [Dispell](Dispell.md) or a [Swordman](Swordman.md)'s [Provoke](Provoke.md).
*  Changing to any other class (including [Super Novice](Super_Novice.md)) makes the skill unavailable upon relog/mapchange.
