# Lex Divina

<!-- Skill info -->
- **Class:** Priest
- **Secondary class:** Mercenary
- **Type:** Supportive
- **Levels:** 10 (Fixed)
- **Prerequisites:** ([Acolyte](Acolyte.md)) [Ruwach](Ruwach.md) Lv. 1
- **Cast time:** None
- **Delay:** 3 seconds
- **Status:** [Silence](Status_Effects.md)
- **Target:** Monsters & Players (Except Self)


## Description

Inflict the [Silence](Status_Effects.md) status on a target by chance. Lex Divina cannot be used on [Boss](Boss_Protocol.md) monsters. When a target is already [Silenced](Status_Effects.md), this skill will remove the [Silence](Status_Effects.md) status.

The skill can be used on silenced party members by holding Shift and targetting a party member as you would an enemy.
