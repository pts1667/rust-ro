# Talkie Box

<!-- Skill info -->
- **Class:** Hunter
- **Type:** Active
- **Levels:** 1
- **Prerequisites:** ([Hunter](Hunter.md)) [Remove Trap](Remove_Trap.md) Lv. 1, [Shockwave Trap](Shockwave_Trap.md) Lv. 1
- **SP cost:** 10
- **Cast time:** None
- **Delay:** [ASPD](ASPD.md) Based
- **Duration:** 600 seconds
- **Target:** Ground
- **Range:** Melee
- **Catalyst:** 1 Trap


## Description

Set a trap that will display a prerecorded text message to whoever steps on it.


## Notes

Useful for alerting other players when there is a [MVP](MVP.md) in the connecting map.
