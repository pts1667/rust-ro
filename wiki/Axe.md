# Axe

Axes can be used by [Swordman](Swordman.md), [Knight](Knight.md), [Crusader](Crusader.md), and [Assassin](Assassin.md), but are generally used by [Merchant](Merchant.md), [Alchemist](Alchemist.md), [Blacksmith](Blacksmith.md) classes. Axes come in many varieties, with more slotted versions being dropped by monsters. Axes have medium-high to high [ATK](Stats.md), but have lower attack speed than swords or daggers. Many axes are sold from NPCs. All axes are also naturally unbreakable except in upgrade attempts.

| Size | Damage |
| --- | --- |
| [Small](Size.md) | 50% |
| [Medium](Size.md) | 75% |
| [Large](Size.md) | 100% |

Note: Forge denotes the [Blacksmith](Blacksmith.md) ability [Smith Axe](Smith_Axe.md). These versions have 0 slots, but can have elemental or strong modifiers.
