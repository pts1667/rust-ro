# Status Recovery

<!-- Skill info -->
- **Class:** Priest
- **Type:** Supportive
- **Levels:** 1
- **Prerequisites:** None
- **SP cost:** 5
- **Cast time:** None
- **Delay:** 2 seconds
- **Target:** Monsters & Players
- **Status:** [Blind](Status_Effects.md)


## Description

Cures the target from [Frozen](Status_Effects.md), [Stoned](Status_Effects.md) and [Stun](Status_Effects.md) status effects.


## Note

* When Status Recovery is cast on [Undead](Undead.md) element monsters, it will inflict the [Blind](Status_Effects.md) status.
* Casting Status Recovery on an aggressive monster will make it aquire a new target (which may include the old target).
* When used on a passive monster currently attacking a player, it will reset the monster to its passive state.
