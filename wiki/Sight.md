# Sight

<!-- Skill info -->
- **Class:** Mage
- **Secondary class:** Super Novice
- **Tertiary class:** Mercenary
- **Type:** Active
- **Levels:** 1
- **Prerequisites:** None
- **SP cost:** 10
- **Cast time:** None
- **Delay:** None
- **Target:** Self
- **Area:** 7x7


## Description

Summon a fire ball that will spin around and detect hidden enemies within a 7*7 cell area around the caster without doing any damage. Can be used in conjunction with [Wizard](Wizard.md)'s Sightrasher, and [Sight Blaster](Sight_Blaster.md).

Does not reveal [Stalker](Stalker.md)s using [Stealth](Stealth.md).

This skill can be obtained via the use of a Horong Card.
