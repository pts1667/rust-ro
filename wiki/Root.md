# Root

<!-- Skill info -->
- **Class:** Monk
- **Type:** Active
- **Levels:** 5 (Fixed)
- **Prerequisites:** ([Monk](Monk.md)) [Flee](Stats.md) Lv. 5
- **SP cost:** 10
- **Cast time:** 0.5-1.3 seconds
- **Delay:** 0.5 seconds
- **Duration:** (10 + (Skill level*10)) seconds
- **Target:** Enemy (None Needed)
- **Range:** Melee


## Description

Root is the [Monk](Monk.md)'s version of the [Knight](Knight.md) skill [Counter Attack](Counter_Attack.md). Once Root is cast, it allows the caster to "catch" an enemy if they use a normal attack against the caster during the skill's Catch Time. If Root is successfully casted, then both the [Monk](Monk.md) and enemy are thrown into the "Root" status. During the Root status, only the caster may attack, by use of skills, and what skills they can use are determined by the level of Root they have learned (exception if the opponent is also a monk, see notes). Root only works on physical attacks and requires 1 [Spirit Sphere](Spirit_Sphere.md) per cast, regardless if an enemy is caught or not.

| Skill Level | Skills | Catch Time | Duration |
| --- | --- | --- | --- |
| 1 | None | .5 seconds | 20 seconds |
| 2 | [Throw Spirit Sphere](Throw_Spirit_Sphere.md) | .7 seconds | 30 seconds |
| 3 | [Occult Impaction](Occult_Impaction.md) | .9 seconds | 40 seconds |
| 4 | [Raging Quadruple Blow](Raging_Quadruple_Blow.md) | 1.1 seconds | 50 seconds |
| 5 | [Guillotine Fist](Guillotine_Fist.md) | 1.3 seconds | 60 seconds |

The Catch Time associated with Root is the amount of time you have to actually "catch" an enemy attack to launch the Root status.


## Continuing as a Combo

[Guillotine Fist](Guillotine_Fist.md) only requires 4 [Spirit Sphere](Spirit_Sphere.md)s to be cast in the Root status (since Root takes one [Spirit Sphere](Spirit_Sphere.md) to cast) but still requires the [Fury](Fury.md) state.

It is possible to continue the [Raging Quadruple Blow](Raging_Quadruple_Blow.md) to [Raging Thrust](Raging_Thrust.md) if you select the enemy just after quadruple. This way, it is possible use the folowing combos:
*  Root -> [Raging Quadruple Blow](Raging_Quadruple_Blow.md) -> [Raging Thrust](Raging_Thrust.md) ([Monk](Monk.md)/[Champion](Champion.md))
*  Root -> [Raging Quadruple Blow](Raging_Quadruple_Blow.md) -> [Raging Thrust](Raging_Thrust.md) -> [Glacier Fist](Glacier_Fist.md) ([Champion](Champion.md))
*  Root -> [Raging Quadruple Blow](Raging_Quadruple_Blow.md) -> [Raging Thrust](Raging_Thrust.md) -> [Chain Crush Combo](Chain_Crush_Combo.md) ([Champion](Champion.md))
*  Root -> [Raging Quadruple Blow](Raging_Quadruple_Blow.md) -> [Raging Thrust](Raging_Thrust.md) -> [Glacier Fist](Glacier_Fist.md) -> [Chain Crush Combo](Chain_Crush_Combo.md) ([Champion](Champion.md))
*  Root -> [Raging Quadruple Blow](Raging_Quadruple_Blow.md) -> [Raging Thrust](Raging_Thrust.md) -> [Chain Crush Combo](Chain_Crush_Combo.md) -> [Guillotine Fist](Guillotine_Fist.md) ([Champion](Champion.md), needs to have 1 [Spirit Sphere](Spirit_Sphere.md) at the end of [Chain Crush Combo](Chain_Crush_Combo.md) and be in [Fury](Fury.md) state)


## Notes

*  Root cannot catch players or monsters using skills.
*  Since this skill is of the [Monk](Monk.md) discipline, if the user Roots an enemy [Monk](Monk.md), then the enemy can also use skills while in Root; which skills are available is determined by each player's level of Root.
*  During the Root status, players/monsters will retain all of their original characteristics, *except* the inability to move or attack. They can be damaged, attacked, use items or even change gears.
*  Rooted players/monsters are also susceptible to effects like knockback (and it will not affect the Root status).
*  [Throw Spirit Sphere](Throw_Spirit_Sphere.md) is weakened when used from Root, as Root itself consumes one spirit sphere.
*  Root only works from melee range. It can be used against ranged attackers, but the monk using Root must be within melee range.
