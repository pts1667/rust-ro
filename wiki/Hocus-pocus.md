# Hocus-pocus

<!-- Skill info -->
- **Class:** Sage
- **Type:** Active
- **Levels:** 10
- **Prerequisites:** ([Sage](Sage.md)) [Dispell](Dispell.md) Lv. 1, [Hindsight](Hindsight.md) Lv. 5, [Magnetic Earth](Magnetic_Earth.md) Lv. 1
- **SP cost:** 50
- **Cast time:** None
- **Catalyst:** 2 Yellow Gemstones


## Description

Cast a skill that is randomly chosen from among character and monster skills in Ragnarok Online, and a few unique skills that can only be cast through Hocus-pocus. The skill`s level affects the variety of skills that can be cast. Each cast consumes 2 Yellow Gemstones regardless of skill level. If the caster is equipped with the Mistress Card or is benefiting from the [Power Cord](Power_Cord.md) skill, Hocus-pocus will still require 1 Yellow Gemstone.

* **Note**: On iRO, this skill has been disabled in [War of Emperium](War_of_Emperium.md) Castles.


## Hocus-pocus Skills


## Beastly Hypnosis

Tame a monster like if a taming item was used on it. Only works on monsters that can become pets. This skill shows up as "????" in game prior to targeting it on a monster.


## Class Change

Used on a monster. The monster then turns into a random [MVP](MVP.md). If used on a mini boss, the boss will not spawn again until the created MVP is killed.  These MVPs, like regular MVPs, are considered [Free for All](Free_for_All.md). This skill shows up as "????" in game prior to targeting it on a monster.


## Coma

Automatically used on yourself - your [HP](Max_HP.md) and [SP](SP.md) drop down to 1.


## Gold Digger

Steals [Zeny](Zeny.md) from a monster like a [Rogue's](Rogue.md) [Mug](Mug.md). 100% chance of success.
* **Note:** This skill is no longer available from Hocus-pocus


## Grampus Morph

Makes caster's head become an orc head.


## Gravity


## Grim Reaper

Used on a monster. The monster dies instantly without giving exp or loot. Cannot be used on [boss](Boss_Protocol.md) monsters. This skill shows up as "????" in game prior to targeting it on a monster.


## Leveling

Gives the caster 10% [Base EXP](Base_EXP_Chart.md). It's always 10%, base level does not matter. If done while inside [Bard](Bard.md)/[Dancer](Dancer.md)'s [Mental Sensing](Mental_Sensing.md), [EXP](Experience.md) is increased.
* **Note:** This skill is no longer available from Hocus-pocus


## Mono Cell

Used on a monster. The monster turns into a Poring. If used on a mini boss, the boss will not spawn again until this Poring is killed. Cannot be used on [boss](Boss_Protocol.md) monsters. This skill shows up as "????" in game prior to targeting it on a monster.


## Monster Chant

Just like a Dead Branch - summons a random monster.  Monsters summoned via Hocus-pocus are considered [Free for All](Free_for_All.md).


## Questioning

Does the /? emote.


## Rejuvenation

Restores [HP](Max_HP.md) and [SP](SP.md) back to full.


## Suicide

Automatically used on yourself - instant death.
