# Estin

<!-- Skill info -->
- **Class:** Soul Linker
- **Type:** Offensive
- **Levels:** 7
- **Prerequisites:** ([Soul Linker](Soul_Linker.md)) [Wizard Spirit](Wizard_Spirit.md) Lv.1
- **SP cost:** 16 + (Skill Level * 2)
- **Cast time:** 0.1 second
- **Delay:** 0.5 second
- **Target:** Monster
- **Range:** Magic
- **Knockback:** 3


## Description

Push back a targeted monster 2 cells away. Only [Small](Size.md) sized monsters are damaged by this skill, which takes the elemental property of the [Mild Wind](Mild_Wind.md) skill if it is cast. At skill level 7, after casting Estin there will be a 3 second interval that will allow the casting of the skill [Esma](Esma.md). SP cost is affected by [Kaina](Kaina.md).
