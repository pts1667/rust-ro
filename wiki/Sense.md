# Sense

<!-- Skill info -->
- **Class:** Wizard
- **Secondary class:** Sage
- **Tertiary class:** Mercenary
- **Type:** Active
- **Levels:** 1
- **Prerequisites:** None
- **SP cost:** 10
- **Cast time:** None
- **Delay:** None
- **Target:** Foe


## Description

Analyze a target, revealing information such as its HP, SP, [Element](Element.md), [Size](Size.md), and [Race](Race.md). If the caster is in a party, all party members can see the target`s information.


## Notes

*  Player cast Sense will see only Armor (hard) [DEF](DEF.md) and [MDEF](Stats.md), while Mercenary cast Sense will see only VIT/INT (soft) DEF and MDEF.
*  Sense cannot be cast on other players.
