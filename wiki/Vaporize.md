# Vaporize

<!-- Skill info -->
- **Class:** Alchemist
- **Type:** Supportive
- **Levels:** 1
- **Prerequisites:** ([Alchemist](Alchemist.md)) [Bioethics](Bioethics.md) Lv. 1
- **SP cost:** 50
- **Target:** Homunculus


## Description

Vaporize Homunculus into a form that is much easier to carry around. This skill is only usable if Homunculus has at least 80% of it's [Max HP](Max_HP.md). Vaporized Homunculus can be restored with the [Call Homunculus](Call_Homunculus.md) skill.
