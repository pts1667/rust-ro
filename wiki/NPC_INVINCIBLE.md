# NPC INVINCIBLE

> **Npc skill** — name: Invincible; type: Single Target Support; levels: 1; target: Self

Changes a monster to Plant Type (99 def / 100 mdef), resulting in 1 damage from all attacks until the status is canceled either by the monster or a map trigger.
