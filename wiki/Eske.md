# Eske

<!-- Skill info -->
- **Class:** Soul Linker
- **Type:** Offensive
- **Levels:** 3
- **Prerequisites:** ([Soul Linker](Soul_Linker.md)) [Crusader Spirit](Crusader_Spirit.md) Lv.1, [Knight Spirit](Knight_Spirit.md) Lv.1
- **SP cost:** 60 - (Skill Level * 15)
- **Cast time:** 4 - (Skill Level) seconds
- **Delay:** 0.5 seconds
- **Duration:** 10*(Skill Level) seconds
- **Target:** Monster


## Description

Increase targeted monster's [ATK](Stats.md) 4x, but reduce its [DEF](DEF.md) by half. Following the casting of this skill [Esma](Esma.md) can be used for the next 3 secs.

Like all Es Skills, this can be only casted on monsters. Using this on other players causes the skill to fail and the caster to be [stunned](Status_Effects.md).
