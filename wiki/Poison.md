# Poison

**For the status effect, see [Status Effects#Poison](Status_Effects.md).**

Elemental Property. Poison Property should not be confused with the Status Effect. The [Assassin](Assassin.md) skill [Enchant Poison](Enchant_Poison.md) can change a weapon's element to poison.

## Cards

Cards which concern the Poison property include:


## Armor

* Argiope Card: Enchant an Armor with the Poison property. DEF +1


## Head Gear

* Ghoul Card: Increase resistance to Poison property attacks by 20%. DEF +1


## Weaponry

* Anacondaq Card: Increase damage on Poison property monsters by 20%.


## Garment

* Myst Card: Increase resistance to the Poison property by 30%. Flee Rate +5
