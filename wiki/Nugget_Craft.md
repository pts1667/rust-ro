# Nugget Craft

<!-- Skill info -->
- **Class:** Mastersmith
- **Type:** Active
- **Levels:** 3
- **Prerequisites:** ([Blacksmith](Blacksmith.md)) [Ore Discovery](Ore_Discovery.md) Lvl. 1, [Oridecon Research](Oridecon_Research.md) Lvl. 3, [Weaponry Research](Weaponry_Research.md) Lvl. 5
- **SP cost:** N/A
- **Target:** Self


## Description

Create a gold piece using Iron Ore, Gold Ore, or Silver Ore, then combine it to create a nugget. This nugget will be used to create specific weapons, or it can be sold to [NPC](NPC.md)s for a high price, or to create coins with. It can also be used to increase your chance of making a weapon.
