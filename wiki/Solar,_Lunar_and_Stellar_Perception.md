# Solar, Lunar and Stellar Perception

<!-- Skill info -->
- **Class:** TaeKwon Master
- **Type:** Active
- **Levels:** 3
- **Prerequisites:** None
- **SP cost:** 100


## Description

Aligns a map as a place of the Sun, Moon, or Stars. Once a map has been aligned, it is *virtually permanent**and cannot be reassigned without performing the lengthy [reset procedure](TaeKwon_Master.md). Aligning a map allows the respective Heat and Protection skills to be used on it. [Solar, Lunar and Stellar Courier](Solar,_Lunar_and_Stellar_Courier.md) will activate on any aligned map. Using this skill after already aligning a map will display the name of your aligned map.**It's unwise to align [instanced](Instance.md) maps because alignments do not apply to other instances of the same map.'*

| Level | Effect |
| --- | --- |
| 1 | The map is aligned as a place of the sun. |
| 2 | The map is aligned as a place of the moon. |
| 3 | The map is aligned as a place of the stars. |
