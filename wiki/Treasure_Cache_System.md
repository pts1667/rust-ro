# Treasure Cache System


## Overview

Throughout every map on the Classic server are monsters (mimics) labelled "Cache Me".
The cache monsters take 1 damage from all sources and drop a "Treasure Cache".

These Caches are taken to "Treasure Cache Opener" on the right hand side of Asgard village. (asgard_vil 131, 112)

Each Cache requires a Key to open.

Caches are **character bound**.


## Keys

Keys can be obtained in the following ways

| Silver Key | tbd (Community events) |
