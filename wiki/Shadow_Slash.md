# Shadow Slash

<!-- Skill info -->
- **Class:** Ninja
- **Type:** Offensive
- **Levels:** 5
- **Prerequisites:** ([Ninja](Ninja.md)) [Haze Slasher](Haze_Slasher.md) Lv. 5
- **SP cost:** (12 + (Skill Level*2))
- **Target:** Foe
- **Range:** 6-10 cells


## Description

Strike a target with an attack whose range is equal to the caster's [Shadow Leap](Shadow_Leap.md) range. Shadow Slash can only be performed during [Hiding](Hiding.md) status, which can be enabled by the [Haze Slasher](Haze_Slasher.md) skill or using the effect of Smokie Card. Casting this skill will cancel Hiding status. Cannot be used in WoE since the 2/13/07 patch.
