# Falconry Mastery

<!-- Skill info -->
- **Class:** Hunter
- **Type:** Passive
- **Levels:** 1
- **Prerequisites:** ([Hunter](Hunter.md)) Lv. 1 [Beast Bane](Beast_Bane.md)


## Description

Enables [Hunter](Hunter.md)s to rent and command a Falcon, an exclusive sub-character for the Hunter class.


## Information

* Falcons can be purchased at the [Hunter](Hunter.md) guild.
* Falcons require no special attention (i.e. food) and should only leave their master if said master decides to unequip it. It can then be re-purchased for 2,500 [Zeny](Zeny.md).
* However, leaving the equipment window open for a long duration of time can cause the Falcon the disappear. This is a bug, but a new one will still have to be purchased.
