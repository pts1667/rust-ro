# Movement Speed

Movement Speed is the speed the player walks at. It is not affected by [AGI](Stats.md), only by certain skills and items. A character with no speed modifying effects will take 0.15 seconds to move 1 cell.

| Movement | Modifier Movement Speed (Second/cell) |
| --- | --- |
| No Movement Modifiers | 0.15 |
| [Increase AGI](Increase_AGI.md) | 0.11 (~140% normal movement speed) |
| [Peco Peco Ride](Peco_Peco_Ride.md) | 0.11 |
| Increase AGI and Peco Peco Ride | 0.07 (~200% normal movement speed) |
| Speed Potion | 0.06 (~250% normal movement speed) |

The following items provide a bonus identical to, and do not stack with [Increase AGI](Increase_AGI.md)

* Authoritative Badge (180%)
* Box of Thunder (200%)
* Bloody Axe (140%)
* PecoPeco Hairband (140%)
* Any item which offers increased movement speed.

It is likely that almost any item or skill that says it increases movement rate behaves in this way as well.

The following skills increase movement speed by some degree:

* [Cart Boost](Cart_Boost.md) (Said to be slightly slower than Agi Up, and does not stack)
* [Wind Walker](Wind_Walker.md) (Does not stack with Agi Up)
* [Improve Dodge](Improve_Dodge.md) (For [Assassin](Assassin.md)s only)
* [Cloaking](Cloaking.md) (boost is greater next to walls)
* [Urgent Escape](Urgent_Escape.md) (For [Alchemist](Alchemist.md)s with the homunculus [Lif](Lif.md))
* [Solar, Lunar and Stellar Union](Solar,_Lunar_and_Stellar_Union.md)

The following skills and effects reduce movement speed by some degree:

* [Pushcart](Pushcart.md) (Reduces movement speed by 50% - 5%*Skill Level while cart is equipped)
* [Quagmire](Quagmire.md) (also cancels most movement speed and ASPD increasing effects)
* [Decrease AGI](Decrease_AGI.md)
* [Slow Grace](Slow_Grace.md)
* [Curse](Status_Effects.md)
* [Battle Chant](Battle_Chant.md) movement & attack speed reduction
* [Mental Strength](Mental_Strength.md) (if the user is [Curse](Status_Effects.md)d while in MS, they will actually walk faster because their movement speed is overwritten by that of [Curse](Status_Effects.md), which is not as slow)
* [Stalk](Stalk.md) (Works the same as Mental Strength)

A Speed Potion does not stack with any other speed increases, and cancels most (all?) speed reducing effects. Speed Potions last 5 seconds.
