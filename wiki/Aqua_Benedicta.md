# Aqua Benedicta

<!-- Skill info -->
- **Class:** Acolyte
- **Secondary class:** Super Novice
- **Type:** Active
- **Levels:** 1
- **Prerequisites:** None
- **SP cost:** 10
- **Cast time:** 1 Second
- **Delay:** 0.5 Seconds
- **Catalyst:** 1 Empty Bottle


## Description

Creates a single Holy Water. Can only be used in shallow water.


## Information

*  This skill can be used on [Deluge](Deluge.md).
*  Casting the skill on [Deluge](Deluge.md) does not consume the cells of it, so it is a viable alternative.
*  This skill can also be used on [Watery Evasion](Watery_Evasion.md).
*  Casting the skill on [Watery Evasion](Watery_Evasion.md) will use cells and they will be removed after casting.
*  See [Maps with shallow water](Maps_with_shallow_water.md) for a list of locations to cast.
