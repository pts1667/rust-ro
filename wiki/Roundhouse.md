# Roundhouse

<!-- Skill info -->
- **Class:** TaeKwon Kid
- **Type:** Offensive
- **Levels:** 7
- **Prerequisites:** None
- **SP cost:** (16 - (Skill level*2))
- **Cast time:** None
- **Delay:** [ASPD](ASPD.md)
- **Target:** Foe
- **Range:** Melee
- **Formula name:** Stance
- **Formula value:** [Roundhouse Stance](Roundhouse_Stance.md)


## Definition

To use Roundhouse, the user must first be in the [Roundhouse Stance](Roundhouse_Stance.md).  This kick damages the target, then pushes back enemies around it.  Unfortunately it damages only the target and not the enemies pushed back. Enemies that are pushed back will be stunned at a high chance.
