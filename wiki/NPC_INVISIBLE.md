# NPC INVISIBLE


## Description

*  Supportive skill
*  Levels: 1
*  Duration: 60 seconds

A variant of the Assassin class skill [Cloaking](Cloaking.md). Enables the caster to move while not being seen. Unlike Cloaking, however, attacking or using skills will not cancel the invisible status. Skills that normally reveal people in [Hiding](Hiding.md)/Cloaking status will also work on monsters using Invisible.
