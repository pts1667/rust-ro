# Regeneration

<!-- Skill info -->
- **Class:** Guild
- **Type:** Supportive
- **Levels:** 3
- **Prerequisites:** [Guild Extension](Guild_Extension.md) Lv. 5, [Battle Command](Battle_Command.md) Lv. 1
- **SP cost:** None
- **Cast time:** None
- **Delay:** 5 minutes
- **Area:** Guild Leader's Screen


## Description

All guild members visible on the Guild Leader's screen increase their HP and SP regeneration rate. Once used, caster must wait 5 minutes before using this skill again. Can only be used during guild sieges.

* Is on the same timer as [Restoration](Restoration.md), [Battle Command](Battle_Command.md) and [Urgent Call](Urgent_Call.md).

| Level | Effects |
| --- | --- |
| 1 | 2x HP Regeneration |
| 2 | 2x HP and SP Regeneration |
| 3 | 3x HP and SP Regeneration |
