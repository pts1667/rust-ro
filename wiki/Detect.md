# Detect

<!-- Skill info -->
- **Class:** Hunter
- **Type:** Active
- **Levels:** 4 (Fixed)
- **Prerequisites:** ([Archer](Archer.md)) [Improve Concentration](Improve_Concentration.md) Lv. 1 ([Hunter](Hunter.md)) [Falconry Mastery](Falconry_Mastery.md) Lv. 1
- **SP cost:** 8
- **Cast time:** None
- **Delay:** N/A
- **Target:** Ground
- **Range:** 3~9


## Description

Command your Falcon to detect hidden enemies within a range that is affected by this skill`s level. Each cast consumes 8 SP regardless of this skill`s level.

| Skill Level | Detection Range |
| --- | --- |
| 1 | + 3 cells |
| 2 | + 5 cells |
| 3 | + 7 cells |
| 4 | + 9 cells |
