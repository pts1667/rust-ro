# Remove Trap

<!-- Skill info -->
- **Class:** Hunter
- **Secondary class:** Rogue
- **Tertiary class:** Mercenary
- **Type:** Active
- **Levels:** 1
- **Prerequisites:** ([Hunter](Hunter.md)) [Land Mine](Land_Mine.md) Lv. 1; ([Rogue](Rogue.md)) [Double Strafe](Double_Strafe.md) Lv. 5
- **SP cost:** 5
- **Target:** Trap
- **Range:** Melee


## Description

With the help of this skill, one can safely remove traps laid by yourself.


## Information

* Usable in [PvM](PvM~a1fb2.md), [PvP](PvP~d29d2.md) and [WoE](War_of_Emperium.md).
* Does not remove monster set traps.
* Can remove traps set by other players in PvP and WoE.
* Even if a trap cost 2 items originally, removing one gives back only 1 trap item.
* It can be used on already active traps, like [Ankle Snare](Ankle_Snare.md).
