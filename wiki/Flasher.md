# Flasher

<!-- Skill info -->
- **Class:** Hunter
- **Type:** Active
- **Levels:** 5 (Selectable)
- **Prerequisites:** ([Hunter](Hunter.md)) [Skid Trap](Skid_Trap.md) Lv. 1
- **SP cost:** 12
- **Cast time:** None
- **Delay:** [ASPD](ASPD.md) Based
- **Duration:** (180 - (Skill level*30)) seconds
- **Target:** Ground
- **Range:** Melee
- **Status:** [Blind](Status_Effects.md)
- **Catalyst:** 1 Trap


## Description

Set a trap that will emit a light that may inflict enemies with the [Blind](Status_Effects.md) status. When cast, Flasher consumes 12 SP and 1 Trap item regardless of skill level.  As skill level increases, blind duration or chance (unsure which, please verify) increases.

| Skill Level | Trap Duration |
| --- | --- |
| 1 | 150 sec |
| 2 | 120 sec |
| 3 | 90 sec |
| 4 | 60 sec |
| 5 | 30 sec |
