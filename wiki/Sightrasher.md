# Sightrasher

<!-- Skill info -->
- **Class:** Wizard
- **Type:** Offensive
- **Levels:** 10 (Selectable)
- **Prerequisites:** ([Mage](Mage.md)) [Sight](Sight.md) Lv. 1, [Lightning Bolt](Lightening_Bolt.md) Lv. 1
- **SP cost:** (33 + (Skill Level*2))
- **Cast time:** .5 seconds
- **Delay:** 2 seconds
- **Knockback:** N/A
- **Element:** Fire


## Description

This skill can only be used after [Sight](Sight.md) has been cast and is active. Sightrasher projects the fireballs summoned from Sight in 8 directions around the caster. These fireballs will inflict [Fire](Fire.md) damage and push back enemies.
