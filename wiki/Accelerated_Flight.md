# Accelerated Flight

<!-- Skill info -->
- **Class:** Filir
- **Secondary class:** Alchemist
- **Tertiary class:** Homunculus
- **Type:** Active
- **Levels:** 5 (Selectable)
- **Prerequisites:** ([Filir](Filir.md)) [Flitting](Flitting.md) Lv. 3
- **SP cost:** 20 + Skill Level*10
- **Cast time:** None
- **Delay:** (1~4) (50 + (Skill level*10)) seconds; (5) 120 seconds
- **Duration:** (65 - (Skill level*5)) seconds
- **Target:** Filir


## Description

Increase the Filir's Flee.
