# Downloads

iRO Wiki hosts several types of downloads:

* Clients and Patches - The Current iRO Full Client and all previous iRO patch downloads.
* [Tools](Tools.md) - Tools to view and extract from the game client.
* [AI](AI.md) - Custom and Default AIs for [Homunculus](Homunculus_System.md) and [Mercenaries](Mercenary_System.md).
* [BGM Files](BGM_Files.md) - Custom and Future BGM files in .mp3 format.
* [Sound Effects](Sound_Effects.md) - Skill sounds from the game.
* [Game Art](Game_Art.md) - iRO Loading Screens and [NPC](NPC.md) illustrations from the game client.
* [Skins](Skins.md) - Custom Skin files for both in-game and the patch client.
