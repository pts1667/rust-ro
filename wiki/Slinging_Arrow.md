# Slinging Arrow

<!-- Skill info -->
- **Class:** Dancer
- **Type:** Offensive
- **Levels:** 5
- **Prerequisites:** ([Dancer](Dancer.md)) [Dance Lessons](Dance_Lessons.md) Lv.3
- **SP cost:** (1 + 2*(Skill Level - 1))
- **Delay:** 1.5
- **Target:** Enemy
- **Catalyst:** 1 Arrow
- **Weapon:** Whip


## Description

Ranged whip attack, slings an arrow (used) at an enemy. The attack's property is determined by the property of the caster's equipped arrow. This skill can be used while using a [Performance Skill](categories/Performance_Skills.md).
