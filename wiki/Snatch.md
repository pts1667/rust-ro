# Snatch

<!-- Skill info -->
- **Class:** Rogue
- **Type:** Offensive
- **Levels:** 5 (Selectable)
- **Prerequisites:** ([Rogue](Rogue.md)) [Sightless Mind](Sightless_Mind.md) Lv. 5, [Back Stab](Back_Stab.md) Lv. 4
- **SP cost:** 13~24
- **Cast time:** None
- **Delay:** N/A
- **Target:** Enemy
- **Range:** Melee


## Description

Strike a target and immediately warp the target and caster to a random location on the same map. The greater the caster`s level when compared to the target`s level, the higher the success rate of this skill. Snatch is ineffective against Boss Monsters. Can not be used in [PvP](PvP~d29d2.md) rooms or [WoE](War_of_Emperium.md), but can be used in Guild Dungeons.

Level 6 and above can only be acquired by a [Rogue](Rogue.md)/[Stalker](Stalker.md) with [Intimidate](Intimidate.md) copying Snatch from Samurai Specter.


## Skill Development

The Snatch skill was previously able to be used in [PvP](PvP~d29d2.md) rooms as well as WoE. Its teleporting ability has been removed ever since Butterfly Wings were made usable inside buildings/pvprooms.
This is due to Rogue class being able to teleport in [WoE](War_of_Emperium.md), which led the development team to disable the use of the skill in PvP environment. (e.g. PvP and WoE in non-PK servers.)
