# Christmas Carol

<!-- Skill info -->
- **Type:** Active
- **Levels:** 1
- **Prerequisites:** Must have a Christmas Musicbox Equipped
- **SP cost:** 1
- **Delay:** 60s+


## Description

Using this skill plays the melody "We Wish You a Merry Christmas". It can be heard by all players nearby.


## Obtainable via.

*  Christmas Musicbox - through the 2008 Christmas Event Quest
