# NPC EXILE

> **Npc skill** — name: Exile; type: Single Target; levels: 1; range: 7 Cells


## Description

Also referred to as Expulsion or Banishment.  When cast it forces the player to [Teleport](Teleport.md) to a random location on the map as if they had used the teleport skill as well as doing damage.  Has a visual effect that is similar to the skill [Snatch](Snatch.md).
