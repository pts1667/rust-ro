# Cold Bolt

<!-- Skill info -->
- **Class:** Mage
- **Secondary class:** Super Novice
- **Type:** Offensive
- **Levels:** 10 (selectable)
- **Prerequisites:** None
- **SP cost:** (10 + (Skill Level*2))
- **Cast time:** (Skill Level*0.7) seconds
- **Delay:** (.8 + (Skill Level*.2)) seconds
- **Target:** Foe
- **Range:** Magic
- **Element:** Water


## Description

A single target basic [Water](Water.md) elemental attack. The number of hits is dependant on the skill level used. Each hit is based off the user's [MATK](Stats.md). Also, although the animation shows numerous bolts hitting the target in a row, all of the bolts connect "at once" in one bundle of damage.

This skill can be obtained via these items:

*  Ice Falchion - Level 3
*  Level 3 Cold Bolt - Level 3; one time usage
*  Level 5 Cold Bolt - Level 5; one time usage
*  Elemental Sword - Level 3; autocast when attacking
*  Gazeti Card - Level 2; autocast when attacking

This skill can be enhanced with the following item:

*  Siroma Card - Cast time -25%, damage +25%
