# Arrow Shower

<!-- Skill info -->
- **Class:** Archer
- **Secondary class:** Mercenary
- **Type:** Offensive
- **Levels:** 10
- **Prerequisites:** ([Archer](Archer.md)) [Double Strafe](Double_Strafe.md) Lv. 5
- **SP cost:** 15
- **Cast time:** None
- **Delay:** 1 second
- **Target:** Ground
- **Range:** 14 cells
- **Area:** 5x5
- **Knockback:** 2 cells
- **Weapon:** Bow


## Description

Arrow Shower is an [Area of Effect](Area_of_Effect.md) skill, damaging all monsters near the monster the caster targets. The skill level affects the damage inflicted on the enemy.

| Level | Damage |
| --- | --- |
| 1 | 80% |
| 2 | 85% |
| 3 | 90% |
| 4 | 95% |
| 5 | 100% |
| 6 | 105% |
| 7 | 110% |
| 8 | 115% |
| 9 | 120% |
| 10 | 125% |


## Notes

* Arrow Shower hits [cloaked](Cloaking.md) monsters/players.
* Traps can be moved around using this skill, much like how monsters/players are affected by usual knock back skills. Using this method, it is possible to push traps beneath monsters (which is not directly possible).
