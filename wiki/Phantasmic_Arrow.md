# Phantasmic Arrow

<!-- Skill info -->
- **Class:** Hunter
- **Type:** Offensive
- **Levels:** 1
- **Quest:** Hunter Skill Quest
- **SP cost:** 10
- **Cast time:** None
- **Delay:** [ASPD](ASPD.md) Based
- **Target:** Enemy
- **Knockback:** 3 cells
- **Element:** Elements
- **Weapon:** Bow


## Description

Enables the caster to shoot a magic arrow without requiring actual arrows. Inflicts 150% damage and pushes the enemy 3 cells backward after impact.


## Information

* This skill does not take an arrow as one is created for the skill.
* When it hits a target, it always does elemental damage as determined by the arrow.
* If no arrow is equipped, it does [Neutral](Neutral.md) property damage.
* Pushes the enemy back 3 cells.
