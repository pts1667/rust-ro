# Grimtooth

<!-- Skill info -->
- **Class:** Assassin
- **Type:** Offensive
- **Levels:** 5 (Fixed)
- **Prerequisites:** ([Assassin](Assassin.md)) [Cloaking](Cloaking.md) Lv. 2, [Sonic Blow](Sonic_Blow.md) Lv. 5
- **SP cost:** 3
- **Cast time:** None
- **Delay:** [ASPD](ASPD.md) Based
- **Target:** Enemy
- **Range:** 2 + Skill Level
- **Area:** 3x3
- **Weapon:** Katar


## Description

An [Attack](Attacks.md) that hits a 3x3 area around the target with a 200% ATK Modifier. Level 1 and level 2 are considered [Melee](Melee.md) (can be blocked by [Safety Wall](Safety_Wall.md)) while level 3 and above are considered ranged (can be blocked by [Pneuma](Pneuma.md)). Grimtooth stacks with [Enchant Deadly Poison](Enchant_Deadly_Poison.md).

| Level | Cell Range |
| --- | --- |
| 1 | 3 |
| 2 | 4 |
| 3 | 5 |
| 4 | 6 |
| 5 | 7 |


## Notes

* Requires user to be wielding a [Katar](Katar.md) class weapon.
* Requires user to be in the [Hiding](Hiding.md) status.
* The introduction of the quest skill [Venom Knife](Venom_Knife.md) allowed an [Assassin](Assassin.md) to equip arrows. [Arrows](Arrows.md) only work with long range attacks so the only skill [Assassins](Assassin.md) have that will benefit from this is Grimtooth (level 3 or above). Only status arrows work with Grimtooth, not elemental arrows.
* Grimtooth is mostly used as an anti-mob skill. Some players use Grimtooth to kill [Snipers](Sniper.md) in the Somatology Laboratory to level fast. Other uses include mobbing in the Ruins of Juperos.
