# Holy Light

<!-- Skill info -->
- **Class:** Acolyte
- **Type:** Offensive
- **Levels:** 1
- **Quest:** Acolyte Skill Quest#Holy Light Quest
- **SP cost:** 15
- **Cast time:** 2 Seconds
- **Delay:** None ([ASPD](ASPD.md))
- **Target:** Foe
- **Element:** Holy


## Description

Attack a target from a distance with a holy light that inflicts an amount of damage equal to 125% of the caster's [MATK](Stats.md). If a [Priest](Priest.md) uses this skill while endowed with the [Priest Spirit](Priest_Spirit.md) buff Holy Light will deal 5x normal damage, but use 5x more [SP](SP.md).


## Notes

* This skill can inflict damage to any monster, even if they are not [Undead](Undead.md) or [Demon](Demon.md), as long as the monster is not of [Holy](Holy.md) element.
* This skill immediately cancels [Kyrie Eleison](Kyrie_Eleison.md) when used on another player, even if it misses (i.e. the damage is negated entirely).
