# Biochemical Helm

<!-- Skill info -->
- **Class:** Alchemist
- **Type:** Supportive
- **Levels:** 5
- **Prerequisites:** ([Alchemist](Alchemist.md)) [Prepare Potion](Prepare_Potion.md) Lv. 2
- **SP cost:** 20
- **Cast time:** 2 seconds
- **Delay:** 0.5 seconds
- **Target:** Single Ally
- **Catalyst:** 1 [Glistening Coat](Alchemist.md)


## Description

Protect a targeted ally's headgear from damage in battle for a set duration of time which is affected by the level of the skill. Each cast consumes 1 [Glistening Coat](Alchemist.md).

| Skill Level | Skill Duration |
| --- | --- |
| 1 | 120 seconds |
| 2 | 240 seconds |
| 3 | 360 seconds |
| 4 | 480 seconds |
| 5 | 600 seconds |
