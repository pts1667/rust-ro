# Falcon Assault

<!-- Skill info -->
- **Class:** Sniper
- **Type:** Offensive
- **Levels:** 5
- **Prerequisites:** ([Archer](Archer.md)) [Vulture's Eye](Vulture's_Eye.md) Lv. 5, ([Hunter](Hunter.md)) [Steel Crow](Steel_Crow.md) Lv. 3
- **SP cost:** (26 + (Skill level*4))
- **Cast time:** 1.5 second
- **Delay:** 3 seconds
- **Target:** Foe
- **Range:** 9?


## Description

Command the Falcon to deliver numerous blows to a target.

| Column 1 | Column 2 | Column 3 |
| --- | --- | --- |
| **Level** | **Damage** | **SP Cost** |
| **1** | **220%** | **30** |
| **2** | **290%** | **34** |
| **3** | **360%** | **38** |
| **4** | **430%** | **42** |
| **5** | **500%** | **46** |


## Informations

*  Requires a Falcon.
*  The Falcon only delivers 1 actual hit.
*  The damage is calculated the same way as [Blitz Beat](Blitz_Beat.md), based on [DEX](Stats.md) and [INT](Stats.md):
  * (Skill level %)*[Blitz Beat](Blitz_Beat.md) damage
  * Therefore at level 5, this skill will do damage equivalent to [Blitz Beat](Blitz_Beat.md) x 5
*  Falcon Assault bypasses [Guard](Guard.md).
*  Falcon Assault bypasses [Defending Aura](Defending_Aura.md) (not to be confused with the monster variation, [NPC DEFENDER](NPC_DEFENDER.md)).
*  This skill will also bypass Raydric garments if the user has an enchant, endow, or elemental arrows.
*  Sniping Suit is a good armor for those who often use this skill, as this skill has a long reuse delay.
