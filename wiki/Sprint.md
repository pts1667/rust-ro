# Sprint

<!-- Skill info -->
- **Class:** TaeKwon Kid
- **Type:** Active
- **Levels:** 10 Fixed
- **Prerequisites:** None
- **SP cost:** 10~100
- **Cast time:** 0~6 seconds
- **Delay:** 0.5 seconds
- **Duration:** 150 seconds
- **Target:** Self
- **Weapon:** Bare Handed


## Description

When casted, makes the user run at a very high speed in one direction. If there is something obstructing the path of Sprint (obstacles, monsters, characters) in the direction the user was facing when it started, Sprint will be canceled. The user cannot change the direction of movement while sprinting. The Sprint skill also passively increases bare hand damage which ignores [DEF](DEF.md) and has other effects with certain [TaeKwon Kid](TaeKwon_Kid.md) skills.

Sprint can also be canceled if the caster casts Sprint again while Sprinting. The timing on canceling Sprint is attack speed dependent. If the user casts Sprint level 7 or greater, is barehanded, and cancels Sprint soon after initiating the skill, the caster will be launched into the **Spurt** status. The Spurt status lasts for 150 seconds and increases the caster's STR by 10. If the user equips a weapon while in the Spurt status, the Spurt status will be lost.

When Sprint ends, either due to an obstruction or being manually stopped, there is a short delay. The user will be knocked back slightly from the end point if it was ended due to hitting an obstruction.

## Notes

* If the user casts [Flying Kick](Flying_Kick.md) while using Sprint, the damage dealt will increase.
* If the user casts [Flying Kick](Flying_Kick.md) while using Sprint and is in the Spurt status, the damage dealt will increase further.
* If the user is in the Spurt Status, then [Tumbling](Tumbling.md) will also allow the user to dodge melee attacks
* Players and monsters that are moving will not obstruct Sprint.
* This skill is disabled in [Battlegrounds](Battlegrounds.md).
