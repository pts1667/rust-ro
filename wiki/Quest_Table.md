# Quest Table

The purpose of this page is to assist players in finding [Quests](Quests.md) of interest to them.  This page **does not** include [class](Classes.md)-specific quests, quests which give no [EXP](Experience.md) reward, temporary event quests, [Repeatable EXP Quests](Repeatable_EXP_Quests.md) or quests not (yet) available on iRO.

* **Note**: Not all quests are implemented yet. We're updating the ones that aren't with a tag, if one is missing said tag, add it! Visit the Talk page for more information.
* **Note**: This page does not list every variable involved with each quest.  For more information on a particular quest (prerequisite quests, item requirements, item rewards, etc.) please visit that quest's article.
* **Note**: Quest EXP can be wasted.  Look [here](Experience.md) for more information on how exp rewards work.
