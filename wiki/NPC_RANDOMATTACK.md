# NPC RANDOMATTACK


## Description

*  Offensive skill
*  Levels: 10

Deals physical damage to the target. Damage is based on the monster's ATK.

The property of the attack is randomly chosen when the skill is used.

| Skill level | ATK |
| --- | --- |
| 1 | 100% |
| 2 | 200% |
| 3 | 300% |
| 4 | 400% |
| 5 | 500% |
| 6 | 600% |
| 7 | 700% |
| 8 | 800% |
| 9 | 900% |
| 10 | 1000% |
