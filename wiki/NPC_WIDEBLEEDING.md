# NPC WIDEBLEEDING

> **Npc skill** — name: Area Bleeding; type: Multiple Target Status; levels: 5; target: Self

Inflicts [Bleeding](Status_Effects.md) over a large area.

| Skill Level | Area of Effect |
| --- | --- |
| 1 | 5x5 |
| 2 | 11x11 |
| 3 | 17x17 |
| 4 | 23x23 |
| 5 | 29x29 |


## Obtainable via

* Glorious Gladius Lv. 1 when attacking with [Sightless Mind](Sightless_Mind.md)
* Blood Tears Lv. 1 when attacking (Lv. 2 if the upgrade is +9 or higher)
