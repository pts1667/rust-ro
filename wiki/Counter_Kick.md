# Counter Kick

<!-- Skill info -->
- **Class:** TaeKwon Kid
- **Type:** Offensive
- **Levels:** 7
- **Prerequisites:** None
- **SP cost:** (16 - (Skill level*2))
- **Cast time:** None
- **Delay:** [ASPD](ASPD.md)
- **Target:** Foe
- **Range:** Melee
- **Formula name:** Stance
- **Formula value:** [Counter Kick Stance](Counter_Kick_Stance.md)


## Definition

To use Counter Kick, the user must first be in the [Counter Kick Stance](Counter_Kick_Stance.md).  This attack never misses.
