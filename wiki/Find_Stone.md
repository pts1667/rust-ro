# Find Stone

<!-- Skill info -->
- **Class:** Thief
- **Type:** Active
- **Levels:** 1
- **Quest:** Thief Skill Quest#Find Stone Quest
- **SP cost:** 2
- **Cast time:** 0.5 seconds
- **Delay:** [ASPD](ASPD.md) Based
- **Target:** Ground

== Description ==
Enables the caster to create a Stone when the weight of items carried is 50% of the character`s Maximum [Weight Limit](Weight_Limit.md) or less.


## Obtainable Via

* Stapo Card: Allows usage of the skills Find Stone and [Stone Fling](Stone_Fling.md).
