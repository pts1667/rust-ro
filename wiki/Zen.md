# Zen

<!-- Skill info -->
- **Class:** Champion
- **Type:** Active
- **Levels:** 1
- **Prerequisites:** ([Monk](Monk.md)) [Fury](Fury.md) Lv. 5
- **SP cost:** 20
- **Cast time:** 2 seconds
- **Target:** Self


## Description

Attempts to summon all 5 [Spirit Sphere](Spirit_Sphere.md)s at once. Unlike [Summon Spirit Sphere](Summon_Spirit_Sphere.md), this skill can be interrupted.


## Notes

* Zen can be used as an SP recovery skill, since it takes up 20 SP and absorbing 5 spheres would get you 7 x 5 = 35 SP. This method can be used during the 5 minutes delay of [Guillotine Fist](Guillotine_Fist.md) as well.
