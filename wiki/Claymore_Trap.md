# Claymore Trap

<!-- Skill info -->
- **Class:** Hunter
- **Type:** Offensive
- **Levels:** 5
- **Prerequisites:** ([Hunter](Hunter.md)) [Blast Mine](Blast_Mine.md) Lv.1, [Shockwave Trap](Shockwave_Trap.md) Lv.1
- **SP cost:** 25
- **Cast time:** None
- **Delay:** [ASPD](ASPD.md) Based
- **Duration:** (Skill Level*20) seconds
- **Target:** Ground
- **Area:** 5x5
- **Element:** Fire
- **Catalyst:** 1 Trap


## Description

Set a trap that will explode, causing [Fire](Fire.md) property damage to enemies within a 25 cell area. Each cast consumes 25 SP regardless of skill level.

| Skill Level | Trap Duration |
| --- | --- |
| 1 | 20 sec |
| 2 | 40 sec |
| 3 | 60 sec |
| 4 | 80 sec |
| 5 | 100 sec |


## Notes

* Damage Formula: Skill Level * (75 + [ [DEX](Stats.md) / 2]) * {1 + ([INT](Stats.md) / 100)} * Number of stacked monster
