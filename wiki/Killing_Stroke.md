# Killing Stroke

<!-- Skill info -->
- **Class:** Ninja
- **Type:** Offensive
- **Levels:** 10
- **Prerequisites:** ([Ninja](Ninja.md)) [Ninja Aura](Ninja_Aura.md) Lv. 1, [Shadow Slash](Shadow_Slash.md) Lv. 5, [Dagger Throwing Practice](Dagger_Throwing_Practice.md) Lv. 7
- **Range:** 5
- **Target:** Foe
- **Cast delay:** None


## Description

This is a [Ninja](Ninja.md)'s ultimate skill.  This skill can be blocked my [Pneuma](Pneuma.md) and any other skill that can block ranged attacks.  The Ninja must be in the [Ninja Aura](Ninja_Aura.md) status to use this skill and after using this skill the Ninja's HP is reduced to 1.  The damage of Killing Stroke depends on the user's [STR](Stats.md) and [HP](Max_HP.md).

| Skill Level | Damage formula | Sp Cost |
| --- | --- | --- |
| 1 | (STR*40) + (HP*8%) | 55 |
| 2 | (STR*40) + (HP*16%) | 60 |
| 3 | (STR*40) + (HP*24%) | 65 |
| 4 | (STR*40) + (HP*32%) | 70 |
| 5 | (STR*40) + (HP*40%) | 75 |
| 6 | (STR*40) + (HP*48%) | 80 |
| 7 | (STR*40) + (HP*56%) | 85 |
| 8 | (STR*40) + (HP*64%) | 90 |
| 9 | (STR*40) + (HP*72%) | 95 |
| 10 | (STR*40) + (HP*80%) | 100 |


## Notes

*  Base and Weapon [ATK](Stats.md) do not affect this skill
*  This skill will never miss unless under the influence of a skill that blocks ranged attacks
*  Using this skill on Herbs and Mushrooms will result in a miss
*  [Race](Race.md) and [Size](Size.md) cards affect this skill by adding bonus damage
*  The Sign affects this skill by adding bonus damage
*  This skill is always a [Neutral](Neutral.md) elemental attack
*  This skill's damage can only be reduced by cards and **armor** [DEF](DEF.md)
*  In [WoE](War_of_Emperium.md), you will not be [Teleport](Teleport.md)ed to your target.
*  Currently this skill will only deal 50% damage to boss type monsters it is not yet sure if this is intended or a bug
*  The [Ninja](Ninja.md) Aura status is removed immediately after casting Killing Stroke.
