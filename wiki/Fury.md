# Fury

<!-- Skill info -->
- **Class:** Monk
- **Type:** Supportive
- **Levels:** 5
- **Prerequisites:** ([Monk](Monk.md)) [Spiritual Sphere Absorption](Spiritual_Sphere_Absorption.md) Lv. 1
- **SP cost:** 15
- **Cast time:** None
- **Delay:** None
- **Duration:** 180 seconds
- **Target:** Self


## Description

This skill launches the caster into a state that increases the Critical Attack rating of the caster, disables natural SP Recovery, gives the caster a special aura, and allows the user to cast [Guillotine Fist](Guillotine_Fist.md). Additionally, [Snap](Snap.md) does not consume spirit spheres while in fury.  Requires 5 [Spirit Sphere](Spirit_Sphere.md)s to cast.

| Level | +Crit % |
| --- | --- |
| 1 | +10 |
| 2 | +12.5 |
| 3 | +15 |
| 4 | +17.5 |
| 5 | +20 |


## Information

* The disabled natural SP regeneration effect of Fury can be negated when linked with the [Monk Spirit](Monk_Spirit.md).
* SP will still be restored through [Spiritual Cadence](Spiritual_Cadence.md) when sitting.
