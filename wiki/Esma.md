# Esma

<!-- Skill info -->
- **Class:** Soul Linker
- **Type:** Offensive
- **Levels:** 10 (Selectable)
- **Prerequisites:** ([Soul Linker](Soul_Linker.md)) [Estin](Estin.md) Lv. 7, [Estun](Estun.md) Lv. 7
- **SP cost:** 8 * (Skill Level)
- **Cast time:** 2 seconds
- **Delay:** 0.5 seconds
- **Target:** Monster
- **Range:** Magic


## Description

This is a very strong bolt type spell that can change element of its attack depending on [Mild Wind](Mild_Wind.md). This skill can only be used within 3 seconds of casting any of the Spirit Link Spells, or after having cast Estin, Estun or Eske. Damage formula is: (40+[Base Level](Levels.md))% [MATK](Stats.md) * Number of Missiles

Like all Es Skills, this can be only casted on monsters. Damage of Esma is reducable by the monster's [MDEF](Stats.md). Using this skill on other players causes the skill to fail and the caster to be [stunned](Status_Effects.md). SP cost is affected by [Kaina](Kaina.md).
