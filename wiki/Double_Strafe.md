# Double Strafe

<!-- Skill info -->
- **Class:** Archer
- **Secondary class:** Rogue
- **Tertiary class:** Mercenary
- **Type:** Offensive
- **Levels:** 10
- **Prerequisites:** ([Archer](Archer.md)) None; ([Rogue](Rogue.md)) [Vulture's Eye](Vulture's_Eye.md) Lv. 10
- **SP cost:** 12
- **Cast time:** None
- **Delay:** [ASPD](ASPD.md)
- **Target:** Foe
- **Range:** +3 cells
- **Catalyst:** 1 Arrow
- **Weapon:** Bow


## Description

Regular attack with two hits and increased damage.

| Column 1 | Column 2 |
| --- | --- |
| **Level** | **Damage** |
| 1 | 100% x 2 |
| 2 | 110% x 2 |
| 3 | 120% x 2 |
| 4 | 130% x 2 |
| 5 | 140% x 2 |
| 6 | 150% x 2 |
| 7 | 160% x 2 |
| 8 | 170% x 2 |
| 9 | 180% x 2 |
| 10 | 190% x 2 |


## Notes

* The maximum range is always 3 cells longer than a usual attack.
* When you use Double Strafe on the wrong element (0%), you don't see the animation of it, but it uses [SP](SP.md) and 1 arrow.
