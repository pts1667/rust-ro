# Beast Bane

<!-- Skill info -->
- **Class:** Hunter
- **Type:** Passive
- **Levels:** 10
- **Prerequisites:** None


## Description

Increases [ATK](Stats.md) against [Insect](Insect.md) and [Brute](Brute.md) race monsters.

| Level | +[ATK](Stats.md) |
| --- | --- |
| 1 | +4 |
| 2 | +8 |
| 3 | +12 |
| 4 | +16 |
| 5 | +20 |
| 6 | +24 |
| 7 | +28 |
| 8 | +32 |
| 9 | +36 |
| 10 | +40 |


## Notes

This ATK ignores HardDef and Soft Def.
