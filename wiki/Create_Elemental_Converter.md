# Create Elemental Converter

<!-- Skill info -->
- **Class:** Sage
- **Type:** Active
- **Levels:** 1
- **Quest:** Sage_Skill_Quest#Create_Elemental_Converter_Quest
- **SP cost:** 30
- **Cast time:** None
- **Target:** Self
- **Catalyst:** Varies


## Description

Creates an elemental converter. You can create an elemental converter of any of the 4 elements, [Fire](Fire.md), [Earth](Earth.md), [Wind](Wind.md), and [Water](Water.md). These converters can be used with the skill [Elemental Change](Elemental_Change.md) or used on their own to endow yourself with an element for a short period or time. The success rate of creating an elemental converter is 100%.

| Elemental Converter | Required Items |
| --- | --- |
| Fire Elemental Converter | 3 Scorpion Tails Blank Scroll |
| Water Elemental Converter | 3 Snail's Shells Blank Scroll |
| Earth Elemental Converter | 3 Horns Blank Scroll |
| Wind Elemental Converter | 3 Rainbow Shells Blank Scroll |
