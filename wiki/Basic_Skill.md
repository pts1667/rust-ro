# Basic Skill

<!-- Skill info -->
- **Class:** Novice
- **Type:** Passive
- **Levels:** 9
- **Prerequisites:** None
- **Target:** Player


## Description

Enables the use of Basic Interface Skills.

| Skill Level | Skill |
| --- | --- |
| 1 | Enables Trading |
| 2 | Enables Emotions |
| 3 | Enables Sitting |
| 4 | Enables Chat Room Creation |
| 5 | Enables you to join a [Party](Party.md) |
| 6 | Enables use of [Kafra](Kafra.md) Storage |
| 7 | Enables you to organize a Party |
| 8 | Does nothing (Formerly enabled use of the Alignment system) |
| 9 | Allows you to change to a First or Expanded [Class](Classes.md) |
