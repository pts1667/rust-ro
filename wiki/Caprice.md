# Caprice

<!-- Skill info -->
- **Class:** Vanilmirth
- **Secondary class:** Alchemist
- **Tertiary class:** Homunculus
- **Type:** Offensive
- **Levels:** 5 (Selectable)
- **Prerequisites:** None
- **SP cost:** (20 + (Skill Level*2))
- **Cast time:** None
- **Delay:** Animation
- **Target:** Foe
- **Range:** 15 cells (1 cell off of visible screen)
- **Formula name:** Element
- **Formula value:** [Fire](Fire.md), [Water](Water.md), [Wind](Wind.md), [Earth](Earth.md)


## Description

Cast a random bolt skill. The level of the bolt skill cast is affected by the skill level of Caprice.


## Information

This skill will make the Vanilmirth cast one of the following skills at random:

*  [Fire Bolt](Fire_Bolt.md)
*  [Cold Bolt](Cold_Bolt.md)
*  [Lightning Bolt](Lightening_Bolt.md)
*  [Earth Spike](Earth_Spike.md) (For other classes, it is not a bolt-type skill)

These bolt spells are exactly like the mage bolt skills. Each bolt's damage is 100% of Vanilmirth MATK and is reduced by the enemy's MDEF. The cast delay is an animation delay, so a second Caprice can be used once the animation for the previous bolt ends.

Due to the fact that bolts are randomly chosen the player must take caution of the elemental attribute of the monster he/she is fighting, because the casted bolt has a chance of being the same attribute as the target.
