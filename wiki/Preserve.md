# Preserve

<!-- Skill info -->
- **Class:** Stalker
- **Type:** Supportive
- **Levels:** 1
- **Prerequisites:** ([Rogue](Rogue.md)) [Intimidate](Intimidate.md) Lv.10
- **SP cost:** 30
- **Cast time:** 1
- **Delay:** None
- **Duration:** 600 seconds
- **Target:** Self


## Description

Allows [Stalker](Stalker.md)s to not lose the skill learned via [Intimidate](Intimidate.md) even when hit by a different skill for duration of the skill.


## Notes

*  Can be dispelled
