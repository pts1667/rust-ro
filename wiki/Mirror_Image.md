# Mirror Image

<!-- Skill info -->
- **Class:** Ninja
- **Type:** Active
- **Levels:** 10
- **Prerequisites:** ([Ninja](Ninja.md)) [Shadow Slash](Shadow_Slash.md) Lv. 3, [Cicada Skin Shed](Cicada_Skin_Shed.md) Lv. 4, [Ninja Aura](Ninja_Aura.md) Lv. 1
- **SP cost:** 30+((Skill Level - 1) * 2)
- **Delay:** 1 second
- **Duration:** 40 + 20*Skill Level
- **Target:** Self
- **Catalyst:** 1 Shadow Orb


## Description

This ninja skill is extremely similar to [Cicada Skin Shed](Cicada_Skin_Shed.md) because it will dodge all attacks and skills whos damage can be modified by cards. Unlike Cicada Skin Shed though, this skill will not move the caster back 7 cells. This skill requires the Ninja to be in the [Ninja Aura](Ninja_Aura.md) status to use (with this status removed immediately after casting Mirror Image). If Cicada Skin Shed and Mirror Image are active at the same time both skills are triggered.
