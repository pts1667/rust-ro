# Tools

This page lists iRO Wiki hosted game tools. Please feel free to leave any suggestions for other legitimate tools we can host on the Talk page.

* [GRF Builder 1.3](http://downloads.irowiki.org/ragnarok/grfbuilder-0.1.30.zip) - More-featured than GRF Factory, quicker repacking.
* [GRF Update](http://downloads.irowiki.org/ragnarok/grfupdate.zip) - Update data.grf with a .gpf file.
* [GRF Factory](http://downloads.irowiki.org/ragnarok/gf.exe) - Program for opening compressed GRF and GPF files.
* [RGZ Tools](http://downloads.irowiki.org/ragnarok/RGZ_Tools.zip) - Extract and pack .RGZ files.
* [Batch Emblem Extractor](http://downloads.irowiki.org/ragnarok/Emblem%20Extractor.exe) - Program to convert [Guild](Guild_System.md) emblems from the _tmpEmblem folder into a viewable (BMP) format.
* [Single Emblem Extractor](http://downloads.irowiki.org/ragnarok/single_emblem.rar) - GUI program to convert one [Guild](Guild_System.md) emblem at a time into a viewable (BMP) format.
