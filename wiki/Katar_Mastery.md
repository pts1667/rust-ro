# Katar Mastery

<!-- Skill info -->
- **Class:** Assassin
- **Type:** Passive
- **Levels:** 10
- **Prerequisites:** None
- **Weapon:** Katar


## Description

Increases damage of katars. Ignores reductions from Armor and [VIT](Stats.md) Defense. Does not stack with Elemental and Skill modifiers.

| Skill Level | Damage Increase |
| --- | --- |
| 1 | +3 |
| 2 | +6 |
| 3 | +9 |
| 4 | +12 |
| 5 | +15 |
| 6 | +18 |
| 7 | +21 |
| 8 | +24 |
| 9 | +27 |
| 10 | +30 |
