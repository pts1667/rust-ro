# Use iRO

As this wiki is based off the International version of Ragnarok, all data should be reflective of that in this version of the game.  Data such as alternate skill, class, monster, item, and map names and spellings may be noted on the appropriate page, but should **not** be used as the primary page name or reference name throughout the wiki.
