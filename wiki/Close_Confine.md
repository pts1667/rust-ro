# Close Confine

<!-- Skill info -->
- **Class:** Rogue
- **Type:** Active
- **Levels:** 1
- **Quest:** Rogue Skill Quest
- **SP cost:** 25
- **Cast time:** None
- **Delay:** 1 second
- **Duration:** 15 seconds
- **Target:** Enemy
- **Range:** Melee


## Description

Holds a foe interlocked with the caster without either side being able to move, but still being able to attack or use skills and items. Casting it beyond the range of 2 cells results in skill failure. When using this skill, player gains +10 [Flee](Stats.md).


## Note

If Close Confine target is knocked back 3 cells away from the caster (or going beyond the range of 2 cells after the skill is successfully executed), or [hides](Hiding.md) and quickly unhides, the Close Confine status will be canceled.
