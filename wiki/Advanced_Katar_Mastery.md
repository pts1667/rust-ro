# Advanced Katar Mastery

<!-- Skill info -->
- **Class:** Assassin Cross
- **Type:** Passive
- **Levels:** 5
- **Prerequisites:** ([Thief](Thief.md)) [Double Attack](Double_Attack.md) Lv. 5, ([Assassin](Assassin.md)) [Katar Mastery](Katar_Mastery.md) Lv. 7
- **Weapon:** Katar


## Description

Raises damage with [Katar](Katar.md)s by a set percent. Works like a weapon card and only adds damage with skills that count them.

| Level | Damage increase (%) |
| --- | --- |
| 1 | 12 |
| 2 | 14 |
| 3 | 16 |
| 4 | 18 |
| 5 | 20 |
