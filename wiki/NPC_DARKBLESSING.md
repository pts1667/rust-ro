# NPC DARKBLESSING


## Description

* Offensive Skill
* Levels: 1

Instantly reduces the target's HP to 1. This skill can be dodged with Flee.

This effect is similar to the [Coma](Status_Effects.md) status, except it does not affect the player's SP.
