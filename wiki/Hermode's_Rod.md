# Hermode's Rod

<!-- Skill info -->
- **Class:** Gypsy
- **Secondary class:** Minstrel
- **Type:** Active
- **Levels:** 5 (Fixed)
- **Prerequisites:** ([Archer](Archer.md)) [Improve Concentration](Improve_Concentration.md) Lv. 10, ([Dancer](Dancer.md)) [Dance Lessons](Dance_Lessons.md) Lv. 10, ([Bard](Bard.md)) [Music Lessons](Music_Lessons.md) Lv. 10.
- **SP cost:** 10 + (Skill Level*10)
- **Target:** Party


## Skill Description

This skill can only be used near Warp Portals inside Guild Siege maps during [WoE](War_of_Emperium.md) times. Hermode's Rod will cancel all positive statuses, aside from [Berserk](Berserk.md), from all friendly targets except for the caster, and will block any magic spells cast of this skill's targets. No one including the caster can use any skills for the skill's duration, but Hermode's Rod is canceled upon leaving its effective range.

| Level | Duration (seconds) |
| --- | --- |
| 1 | 10 |
| 2 | 20 |
| 3 | 30 |
| 4 | 40 |
| 5 | 50 |
