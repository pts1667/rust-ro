# NPC EMOTION


## Description

*[image not archived: Npc emotion.gif]*

*  Supportive skill
*  Levels: 1

The caster stops whatever action it was doing and displays an emoticon.

Sometimes this skill is used to indicate a temporary change in protocol, such as a monster turning from Aggressive to Passive for a certain time.
