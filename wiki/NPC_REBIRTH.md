# NPC REBIRTH


## Description

*  Supportive skill
*  Levels: 3

When the caster dies, it immediately respawns in the same spot with half HP.

| Skill level | Number of times reviving |
| --- | --- |
| 1 | 0 |
| 2 | 1 |
| 3 | 2 |
