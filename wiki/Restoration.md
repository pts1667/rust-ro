# Restoration

<!-- Skill info -->
- **Class:** Guild
- **Type:** Supportive
- **Levels:** 1
- **Prerequisites:** [Regeneration](Regeneration.md) Lv. 1
- **SP cost:** None
- **Cast time:** N/A
- **Delay:** 5 minutes
- **Area:** Guild Master's Screen


## Description

All guild members visible on the Guild Master's screen will have their HP and SP restored to 90% of the respective maximum. Once used, caster must wait 5 minutes before using this skill again. Can only be used during guild [Siege](Siege.md)s.

* The skill shares the same timer as [Regeneration](Regeneration.md), [Battle Command](Battle_Command.md), and [Urgent Call](Urgent_Call.md).
