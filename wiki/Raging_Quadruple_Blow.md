# Raging Quadruple Blow

<!-- Skill info -->
- **Class:** Monk
- **Type:** Offensive
- **Levels:** 5 (Selectable)
- **Prerequisites:** ([Monk](Monk.md)) [Raging Trifecta Blow](Raging_Trifecta_Blow.md) Lv. 5
- **SP cost:** (Skill Level + 10)
- **Cast time:** None
- **Delay:** 1.3 - [(agi*0.004) - (dex*0.002)] seconds
- **Target:** Enemy ([via Combo](Monk.md))
- **Range:** Melee


## Description

The second skill in the Monk's combo skill set, Raging Quadruple is a more powerful attack that hits four times and must be used in succession immediately after Raging Trifecta Blow (during the "delay" of [Raging Trifecta Blow](Raging_Trifecta_Blow.md)). The only other circumstance when a Monk can successfully perform Raging Quadruple Blow is during a level 4 [Root](Root.md) status. If the user has learned [Raging Thrust](Raging_Thrust.md), then Raging Thrust can be chained after the use of Raging Quadruple Blow.

## Use

Raging Quadruple Blow is not a targeted skill; it strikes the foe currently being attacked by the user when [Raging Trifecta Blow](Raging_Trifecta_Blow.md) triggers. Raging Quadruple Blow should be hotkeyed, and can *only* be activated during the Raging Trifecta Blow delay.

A smart way to use combos is to use quickspell 2 (/q2) and then put Raging Quadruple Blow & [Raging Thrust](Raging_Thrust.md) in the F7 & F8 hotkey slot. This allows scrolling the mouse wheel up or down to trigger the skills; this effectively allows the user to repeat the skills until they trigger while being less distracting then pushing on keyboard hotkeys. It's recommended to deactivate skill fail messages (/skillfail) because it can generate a lot of "skill failed" messages.

A monk can target a different monster with Raging Quadruple blow if he is quick enough to be able to target another monster, as if to do a normal attack, and hit the hotkey during Raging Trifecta Blow's delay.
