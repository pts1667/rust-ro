# Operations checkpoint

Handoff for the "implement all missing operations" goal (pre-renewal only). It lists what exists, what a resuming session must know about the working tree, and the remaining work in priority order. It does **not** claim full pre-renewal coverage. Most work since 2026-10-04 is build-verified only; nothing has been exercised with a live Ragnarok client.

## Implemented

**Platform**
- Sled replaces PostgreSQL (fresh seed from repository assets, no migration); multi-key transactions cover inventory, script variables, world changes, and reward receipts; no explicit flushes.
- Wasmtime runs compiled Rust NPC, item, pet, and event code (SDK, offline import tools, guest sources, manifests, compiled bundle). rAthena is an offline reference and import input only.
- Character admission, map entry, `OnTimerQuit` callbacks, and logout run through the game loop. Login, char selection and map entry are served for every account by the built-in servers; the legacy proxy and `server.accounts` were removed.

**Combat and skills**
- Equipment/card effects, skill resistance, signed elemental absorption, reflection, procs, and monster classes. Resolved damage packets (legacy 16-bit, 2007 32-bit, 2013 SP-aware) are emitted when queued damage is admitted, through one builder for player, monster, NPC, companion, ground, delayed, splash, and reflected hits.
- `SkillDamage` (map, per-skill, and imported rates) and `SkillDuration` (ground unit and trap lifetime) consumers.
- Hunter traps (Skid Trap, Ankle Snare, Land Mine, Shockwave, Sandman, Flasher, Freezing Trap, Blast Mine, Claymore Trap), Remove Trap, Spring Trap, trap durability/knockback/recovery, Talkie Box, Graffiti and Scribble removal, `NoFootSet`/`NoReiteration` placement rules. Config under `game.skill_units`.
- Warp Portal (memo/save-point menu, resource phases, lifecycle, NPC command), `/memo`, `NoSave`, save-point commands, ordered position persistence, normal respawn.
- Demon Shock, Estin, Estun, Esma (`game.allow_es_magic_players`).
- Peco Peco riding: `Character::set_options` keeps `Status.riding` in sync; mounted players get +25% speed, an attack delay penalty of `50% - 10% x Cavalier Mastery`, and +1000 max weight; spear mastery and spear-vs-medium size now see riding. Mounting resends the status block.
- Death penalty (experience, optional zeny, Insurance item), restart HP/SP rates, `NoCommand`, `NoWarp`/`NoWarpTo` for `@warp`/`@go` and party warps.

**Monsters and non-player casts**
- Monster skill AI (`mob_skill_ai.rs`, `config/mob_skills.json` imported from the pre-renewal mob skill database, 5,494 entries). States: idle/walk/chase/attack. Conditions: `always`, `onspawn`, `myhpltmaxrate`, `myhpinrate`, `mystatuson/off`, `friendhpltmaxrate/inrate`, `friendstatuson/off`, `slavelt/le`, `attackpcgt/ge`, `mobnearbygt`, `casttargeted`, `rudeattacked`, `closedattacked`, `longrangeattacked`, `skillused`, `damagedgt`, `afterskill`, `masterattacked`. Direct handlers: `NPC_EMOTION`, `NPC_SUMMONSLAVE`, `NPC_CALLSLAVE`.
- Actor casts: generic `NPC_*` weapon and magic attacks, wide statuses, Fire Ball, Frost Nova, Magnum Break, Palm Strike, Water Ball (single hit), Fire Wall/Storm Gust/Vermilion/Meteor Storm/Earthquake/Grand Cross lifecycles, Self Destruction, Power Up and Defender status mapping. Levels above the metadata maximum are clamped.

**NPC scripting**
- `OnInit`, `OnInstanceInit`, `OnAgitInit`/`OnAgitStart`/`OnAgitEnd` (global broadcast), `getnpcid`, `doevent`, `donpcevent`, NPC and player timers, `OnTimerQuit`, NPC unit-data bridge (46 NPC fields), `setmapflagnosave`, `savepoint`, `getsavepoint`, `setcart`/`setfalcon`/`setriding`, `Marriage`/`Divorce`, `AgitStart`/`AgitEnd`/`AgitCheck`, `GetCastleData`/`SetCastleData` (selectors 1-26). NPC entry 7 (Mount Master, prontera 151,193) exercises the mount and marriage calls.

**Social, guilds, PvP**
- Party, storage, cart, vending, buying store, fame, homunculus, mercenary, pet operations with persistence (partial). Ordinary trading with atomic completion and pet-egg custody. Pet capture/loot and pet automatic bonuses (catalog is empty until an override supplies programs).
- Guilds: 20-slot position table and permissions, notice, emblem, invite/expel, guild chat, member tax, alliances and hostile guilds (packets 0x0170/0x0172/0x0180/0x0183, relation list 0x014C), skill list (0x0162) and skill-up with prerequisites, Guild Extension (+6 members per level).
- Siege: `siege_active`, allied-guild attack block on GvG maps, Emperium (1288) attackable only in an active siege by a non-owner, non-allied guild; its death records the killer's guild as castle owner.
- PvP: night-mare drops, session-only point counters, 0x019A rank packet on kills, forced respawn on GvG/battleground death, duels (`@duel`, `@invite`, `@accept`, `@reject`, `@leave`), fame ranking lists (0x0217/0x0218/0x0225/0x097C), `WE_CALLPARTNER` granted on marriage.

## Build and validation

Run from the repository root with the project's nightly toolchain. Integration tests use temporary Sled databases.

```powershell
cargo build --workspace --release
cargo test --workspace --release --features unit_tests
cargo test --package server --bin server --release --features integration_tests
python -m unittest discover -s tools/scripts-import -p test_mapflags.py
cargo run --package tools --bin scripts-build --release
```

For a fresh local run, copy `config.template.json` to the ignored `config.json`, then run `cargo run --package server --bin server --release`. Include `config/wasm/`, `scripts/` sources and `scripts/Cargo.lock`, import/build tooling, and the new server files in any commit.
